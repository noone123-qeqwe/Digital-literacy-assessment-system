# Dashboard character animation — 16 November 2026

The existing customizable SVG character now blinks, nods gently, types with alternating hands and has a softly pulsing laptop light. Plant leaves sway when the plant is enabled. These details accompany the existing Float and Breathe modes. Choosing None disables all character animation without changing the user's saved appearance.

A keyboard-accessible pause/resume control is available beside Customize character, with 44px targets on phones. The preview has its own access to the same pause state in Motion settings. The dashboard character pauses while the editor is open. Animation also pauses outside the viewport or while the document is hidden, and all motion is disabled for the device's reduced-motion preference. Movement uses CSS transforms and opacity on existing SVG parts, with no additional image downloads, animation library or frame-by-frame JavaScript loop.
